# A Fully Documented Class

**Difficulty:** Easy  
**Course unit:** Unit 5.4 - Documenting Code  
**Context:** Data Science

## Background

The assignment requires complete documentation including docstrings. Here you write a small statistics class where the class and every method carry a docstring, and the methods are also correct.

## Task

Implement a class `Statistics(values)` storing a list of numbers, with methods `mean()` and `std()` (population standard deviation). The class and both methods must have non-empty docstrings.

## Requirements (graded)

- Class and both methods carry non-empty docstrings
- `mean` and `std` compute correct values

## Running the test

From inside this unit folder, run:

```bash
python ex_5_4_1_documented_class.py
```

You will see one PASS/FAIL line per requirement and a final score. The expected values live in `grader.py` in encoded form, so you get feedback on *whether* a requirement is met without seeing the answer.
