# IU - DLMDSPWP01 - Programming with Python - Exercise & Assessment Sandbox


> **Disclaimer:** These are not official university exercises! Since no official practice material exists, I developed these exercises for the "Programming with Python" module to practice the topics from the course script.

## How it Works
The repository is split into unit-based folders. Each exercise includes a professional task description (`.md`) and a template (`.py`) for your code. 

When you run the script, an automatic grading system evaluates your solution against hidden checks encoded in each unit's `grader.py`. This provides instant PASS/FAIL feedback per requirement without revealing the actual answers.


## Working an exercise

1. Open the `.md` next to a template to read the task, difficulty and unit reference.
2. Implement the function(s) in the matching `.py` (keep the given names).
3. Run it from inside the unit folder:

   ```bash
   cd Unit1_Introduction_to_Python
   python ex_1_2_1_least_squares.py
   ```

4. Read the PASS/FAIL feedback and iterate until all checks pass.


## Notes

- Names matter: the grader looks up the exact function/class names from the task.
- Some checks use randomised inputs, so hard-coding answers will not pass.
- Unit 3 exercises need the libraries in `requirements.txt`.
- This is practice scaffolding; it does not contain the graded assignment solution.
